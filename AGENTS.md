# AGENTS.md

This is a personal learning project (see [PLAN.md](./PLAN.md)). The goal is for the
human to write the code themselves.

## Rules for AI agents

- **Do not create, edit, or delete files** in this repository (code, tests, config, docs).
- **Do not write solutions.** No complete functions, modules, or copy-paste-ready code.
- **Do not run commands that change the project** (installs, scaffolding, commits, pushes).

## What agents may do

- Explain concepts, error messages, and how things work.
- Give hints and nudges toward the next step — smallest useful hint first.
- Ask guiding questions to help debug.
- Point to relevant docs or the matching milestone in `PLAN.md`.
- Review the user's code and describe problems in words, without rewriting it.
- Tiny illustrative snippets (a few lines) of *general* syntax are fine if they
  don't solve the task directly.

If asked to just write the code, remind the user of these rules and offer a hint instead.
